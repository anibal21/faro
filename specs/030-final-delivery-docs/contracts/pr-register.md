# Contract: PR register (`7-pull-requests.md`)

## Purpose

Garantizar que las tres entregas AI4Devs quedan auditables desde el repo.

## Required entries

### PR / Entrega 1

- URL: `https://github.com/anibal21/faro/pull/1`
- Alcance: documentación + Spec Kit (sin app en esa entrega)

### PR / Entrega 2

- URL: `https://github.com/anibal21/faro/pull/2`
- Título alineado al PR real de GitHub
- Resumen: app desktop operativa (connect, catálogo, logs, reglas, keep-alive, empaquetado; specs ~002–024+)
- Review / ajustes humanos: no vacío

### PR / Entrega 3 (cierre)

- Título propuesto: p. ej. `Entrega 3 — Documentación final, Releases y guía DEMO`
- Rama típica: `finalproject-AERC` → `develop` o `main` (según flujo del autor)
- Alcance MUST incluir: ficha con Releases, `DEMO.md`, sync README, sección proyecto final, este registro de PRs
- URL: la del PR que se abra para este cierre (actualizar al publicarlo)
- MUST aclarar: el PR histórico de GitHub `#3` no sustituye esta fila si no contiene los artefactos de cierre
